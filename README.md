# Python Tutorials by Jackie Champagne


Welcome to Python Tutorials! This was originally developed by Jackie Champagne as a grad student at UT Austin for the Texas Astronomy Undergraduate Research for Undergraduates (TAURUS) program. It features a ~12-hour workshop split into four days that will get you up to speed on using the terminal and basic Python. Meant for beginners who are starting astronomy research but don't have any computer science background, this will take you from basic command line text editing all the way to using Astropy for image and spectroscopic analysis. 

Feel free to go at your own pace with the Jupyter notebooks (Day* are the main elements of the workshop, while you can try your hand at Advanced Exercises if you're ready!) If you need to start with the terminal, you can find that in the "intro to workshop" PDF. Enjoy!
